# IME アイコンの右クリックメニューの状態表示

メニュー最下部に、選択できない情報行として表示します。
言語バーの `ITfMenu` と、アイコンクリックで出す Win32 ポップアップの両方に対応します。

- エンジン: 通常の RPC 呼び出しの直近の結果と、最終応答からの経過秒。
  30 秒以上応答を確認していない場合は「未確認」、エンジンのロックが使用中なら
  「処理中（状態取得を省略）」と表示します。未接続を正常扱いしません。
- 辞書・モデル: この TSF プロセスが最後に確認した読み込み状態。
  状態の問い合わせをメニュー表示のために追加しません。「最終確認」と明記します。
- 速度: `rakukan-engine-dll.log` の末尾最大 64 KiB から、最後の完了済み
  `beam conversion done` の `elapsed_ms` / `reading_chars` を取得します。
  これはモデル生成の所要時間で、キー入力から候補表示までの総時間ではありません。
  ライブ変換も含み、他のアプリで実行した変換が最後の記録になる場合もあります。
  200 ms 以下を「速い目安」、201～999 ms を「待ち時間あり」、1 秒以上を「遅い目安」
  とし、文字数とログの UTC 記録時刻を併記します。入力本文は表示しません。

状態行の作成はエンジンの起動・推論・追加 RPC を行いません。
既存エンジンへのアクセスは try_lock のみです。ログが無効、未生成、または読めない場合は
「未計測／ログに記録なし」と表示します。古いログを現在の性能保証として扱わないため、
記録時刻も表示します。メニューを開き直すと新しい情報を取得します。

検証:

```powershell
cargo test -p rakukan-engine-rpc -p rakukan-tsf --release --lib --locked --offline
cargo build -p rakukan-tsf --release --locked --offline
```

ログ解析のテストでは、最新の正常な生成記録の選択、不正な値、速度区分の境界を確認します。
