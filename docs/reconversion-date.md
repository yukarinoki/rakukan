# 再変換と日時候補

## 再変換

IME をオンにし、確定済みの文字を選択して **変換キー** または
**Ctrl+Shift+R** を押します。Space / 矢印キーで候補を選び、Enter で確定します。
Escape または Ctrl+Backspace は再変換を取り消して元の文字列を復元します。

- 現在の選択範囲のみを使います。文書末尾への挿入フォールバックは行いません。
- ユーザー辞書、直近の学習履歴、システム辞書の順で読みを復元します。
  同じ表記の複数の読みを候補へ反映します。再変換の結果は読みの曖昧さを考慮して学習対象外です。
  複数単語は辞書の逆引きトークンを組み合わせます。複数の読みがある語は
  元の読みと異なる場合があり、読めない漢字が残る場合は書き換えません。
- 初期候補は元の文字列と辞書候補です。モデルが使用可能なら通常の候補更新経路で
  LLM 候補を追加します。逆引きそのものは LLM に推測させません。
- 空の選択、改行・制御文字、128 文字を超える選択、読み取り専用の文書は対象外です。
- 遅延編集の実行前にフォーカス、選択範囲、内容を再確認します。
- アプリが TSF の選択範囲と composition を提供する必要があります。
  アプリの右クリックメニューから呼ぶ ITfFnReconversion は今回の対象外です。
- 逆引きはホスト側 DLL で行います。各アプリへ辞書やモデルを追加ロードしません。
  RPC の末尾に ReverseReading を追加し、既存のリクエスト番号は維持しています。
  engine_reverse_readings は任意 ABI シンボルなので、旧エンジン DLL は読み取得不可として扱います。

## 日付・時刻

Mozc の [date_rewriter.cc](https://github.com/google/mozc/blob/master/src/rewriter/date_rewriter.cc)
の相対日付キーワードと表記を参考に、Rust でカレンダー候補生成を実装しています。
Mozc 自体へのリンクや C++ ファイル全体の移植ではありません。
参考ファイルのライセンス表記は [MOZC-DATE-LICENSE.txt](MOZC-DATE-LICENSE.txt) に収録しています。

| 読み | 候補 |
|---|---|
| きょう・きのう・あした／あす | 日付、和暦、曜日 |
| おととい・あさって・しあさって など | 対応する日の同形式 |
| げつようび〜にちようび（「び」省略可） | 当日以降の該当曜日の日付 |
| ことし・らいねん・きょねん・おととし・さらいねん | 西暦・和暦の年 |
| こんげつ・らいげつ・せんげつ・せんせんげつ・さらいげつ | 月・年月 |
| いま・じこく | 時:分、時分、時:分:秒 |
| にちじ・なう | 日付と時刻 |

Windows のローカル日時を候補生成時に一度読み、日付の加減算は暦日単位で行います。
候補表示中に日付を跨いだ場合は、変換を開始し直すと更新されます。
通常の単語候補・登録語を残し、日時候補をシステム辞書の残り候補より前に追加します。
日時候補は学習履歴に保存しません。

和暦表記は明治以降を対象にしています。Mozc の歴代元号データ全体、数値入力からの
日付推定、ユーザー辞書の DATE_FORMAT / DATETIME_FORMAT による書式指定は含みません。

## 検証

- 日付: うるう年、2100 年の非うるう年、年越し、月越し、平成/令和境界、曜日、時刻、
  完全一致キー（「きょうと」を日付にしない）、動的候補の学習抑止。
- 逆引き: バイナリ辞書の表記検索、複数語とかなの連結、不明な漢字の拒否。
- 実 DLL: engine-rpc の reconversion_and_date_candidates_through_real_dll を
  RAKUKAN_TEST_ENGINE_DLL 指定で実行でき、登録済み辞書を読み取り専用で使います。
- 実アプリ上の選択 → 候補選択 → 確定 / Escape は、TSF DLL を再読み込みしたアプリで
  別途確認する必要があります。自動テストだけではアプリごとの TSF 対応は保証しません。

Windows の選択範囲は [ITfContext::GetSelection](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfcontext-getselection)、
置換は [ITfContextComposition::StartComposition](https://learn.microsoft.com/en-us/windows/win32/api/msctf/nf-msctf-itfcontextcomposition-startcomposition) を使います。

2026-09-09 の検証結果: release 単体テスト 341 件成功、実 DLL 連携テスト 1 件成功。
「橋」は ばし / きょう / はし の全読みから「箸」を取得でき、逆引きは約 50〜59 ms。
「きょう」で 2026/09/09、「あした」で 2026/09/10、「いま」でローカル時刻を取得しました。
実アプリの画面操作は Computer Use の native pipe 接続不良により未検証です。
